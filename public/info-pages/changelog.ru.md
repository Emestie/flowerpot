## 1.0.1

- исправлена ошибка «exceeded the quota» в блоке пулл-реквестов веб-версии: снимки для уведомлений теперь хранят только поля, нужные для отслеживания изменений, и больше не заполняют локальное хранилище браузера
- сбои сохранения в локальное хранилище больше не ломают загрузку: рабочие элементы и пулл-реквесты продолжают обновляться, даже если браузер не даёт сохранить снимок
- удалена лишняя рамка над рабочими элементами с приоритетом 1
- исправлено контекстное меню рабочих элементов и пулл-реквестов: оно больше не остаётся открытым после клика по другой строке, не открывается само при удержании кнопки мыши, не висит над списком при прокрутке, а повторный клик правой кнопкой по той же строке переносит меню, а не закрывает его
- добавление рабочего элемента в Permawatch или удаление из него больше не перерисовывает весь список: элемент появляется или исчезает сразу, а перезагружается только сам блок Permawatch
- контекстное меню строки в блоке «Наблюдаемые» (Permawatch) теперь предлагает только исключение из этого списка, поэтому перенос элемента в другой список оттуда больше не оставляет в исходном запросе устаревший пункт об исключении из «Наблюдаемых», который ничего не делал
- исправлен запуск на Windows, где системная песочница Chromium не даёт создать окно: если процесс интерфейса падает при старте, Flowerpot перезапускается в режиме совместимости без песочницы, пишет журнал в папку данных и показывает предупреждение с возможностью вернуться в обычный режим; зависший после такого сбоя экземпляр больше не блокирует следующие запуски

## 1.0.0

- После 7 лет разработки Flowerpot, наконец-то, 1.0 🎉🎉🎉
- теперь у каждой новой версии будет уникальное имя, начиная с Aglaonema
- исправлена потеря настроек: файл настроек записывается атомарно и с резервной копией
- если файл настроек повреждён, приложение предупреждает об этом и сохраняет копию повреждённого файла
- добавлена поддержка Azure DevOps Services (облачный DevOps): учётную запись можно подключить по адресу `https://dev.azure.com/organization/` или `https://organization.visualstudio.com/`
- исправлены ссылки на запросы и рабочие элементы при открытии в браузере для облачных учётных записей
- максимальное количество учётных записей увеличено до 5
- исправлено отображение иконок-цветков учётных записей: иконка теперь всегда показывается, в том числе для учётных записей из импортированных настроек
- переключатели включения запросов и проектов в настройках заменены на тумблеры
- добавлена цветовая схема Shire: тёплая землистая палитра со светлой и тёмной стороной
- переработан расчёт цвета иконки в трее: учитываются только включённые запросы без «игнор. икон.», поэтому красная иконка больше не появляется из-за выключенных запросов и не мигает во время обновления
- исправлена ошибка, из-за которой пулл-реквесты с вложенными группами ревьюеров не попадали в список: если пользователь входит в группу, вложенную в группу-ревьюера, такой ПР теперь считается его ПРом
